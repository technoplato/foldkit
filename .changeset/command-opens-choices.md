Command or Control with an Action's key asks which value it acts on: on the counters list, `⌘-` opens the action menu straight at "Decrement › Which counter?" (`/counters/menu?menu.choose=Decrement`), and inside the menu `⌘D` switches to "Delete › Which counter?". The bare key still takes the preferred choice, so `-` on Counter 3's page decrements Counter 3. Web hosts cancel the browser's own shortcut for a chord the Program handles, such as zooming out on `⌘-`. Nothing opens while a dialog is open. `EntryChoices` gains `keys`, the keys the Action declares.
