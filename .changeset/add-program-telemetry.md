Add `Telemetry`, a record of what a running Program does, one NDJSON line per event: each transition with its Message, source, Commands, diff size, and update duration; each Command's span from `CommandStarted` to `CommandFinished` with its args, duration, and `Success`, `Failure`, or `Interrupted`; Subscription and ManagedResource diagnostics; crashes; paints a renderer reports; and the session's start and stop.

Every session declares its surface, named for the Host its handle was started on and never typed by a caller: `terminal-cli`, `terminal-tui`, `terminal-opentui`, `headless`, `web-foldkit`, `web-react`, `web-svelte`, `mobile-ios`, or `mobile-android`, as `Telemetry.surfaceOf(host)` says, so a new Host does not compile until it names one. A process with a job of its own adds a `role`, such as `daemon` for a CLI daemon. Every line carries `app`, `surface`, and `role` when set, so `grep '"surface":"terminal-tui"'` finds every line from the TUI. What a client on another Host causes keeps that client's surface: a `books tui` key the CLI daemon answers records `"surface":"terminal-tui"` on its transition, its Commands, their results, and its frame, beside the daemon's session and `"role":"daemon"`.

`Telemetry.attach(handle, { app, sink, role })` records any handle `Runtime.startHandle` started with a `host`, in React, Foldkit, Svelte, the CLI, the TUI, OpenTUI, or a CLI daemon; a handle started without one is a type error, since it has no surface to record. `Telemetry.observer({ app, host, sink })` does the same for a runtime you start yourself. Sinks are scoped Layers: `Telemetry.browserSink()` posts batches to a development server, and `fileSink()` from `foldkit/telemetry/node` appends to `~/Library/Logs/foldkit/telemetry/<app>-<surface>.ndjson`, such as `books-terminal-tui.ndjson`, rotating at 10 MB, keeping three rotated files, and keeping the whole directory under 200 MB. Message payloads are recorded with secret-looking keys redacted at any depth, whole Models only with `withModels`, and the file sink scrubs environment values out of every line. `foldkit telemetry books --since 30m` reads every surface's file of an app and prints, surface by surface, the top Messages and Actions, the slowest Commands, Command failures, update and render durations, transitions per minute, and Subscription restarts; `--surface web-react` keeps one, and an app's files from before surfaces, such as `books-react.ndjson`, are read with it, each session on the surface its Host names.

To support it, the Program runtime now exposes `programId`, `programVersion`, and `installCommandTracer`, accepts `observers` that connect before it boots, and records `updateDurationMs` on every live transition. `Runtime.startHandle` returns `observeRuntime` and starts its runtime on the next microtask, so an observer connected on the line after it sees the Program boot, and a handle started with a `host` carries it in its type, `Runtime.SyncedHandle<Child, OnHost>`. `Processor.Host.everyHost` lists every Host.
