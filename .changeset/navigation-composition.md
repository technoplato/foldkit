Navigation now composes. `Session.compose` owns the navigation stack: it starts at the child's root under the child's slug, adds the Session settings page at `/counter/session` with the `OpenSessionSettings` and `CloseSessionSettings` Actions, keeps any other path as `NotFound`, treats Escape as Back, and ignores a launch URI while navigation is mirrored so a newcomer joins the shared screen. `ActionMenu.compose` joins an existing stack instead of adding a second one, prints the open menu as `/counter/menu?q=re`, settles the highlighted row when a URI opens it, and now sends `ChoseActionMenuAction` before the chosen Action, so an Action that moves the stack lands beneath the menu. The outermost navigation combinator folds `OpenedUri` and `NavigatedBack`. `Interaction.bind` gains a navigation facet (`navigation`, `viewAt`, `canonicalUri`, `openUri`, `navigateBack`), so a bound Program is the source `runCarrier` drives, and `Program.compose.sync` lifts navigation through `Starting` and `Ready`. `ProgramNavigation` replaces `stackOf` with a `stack` lens and adds `viewOf`, `settleEntry`, `historyOf`, and `adoptsLaunch`. `Session.compose` now requires a child that declares navigation.
