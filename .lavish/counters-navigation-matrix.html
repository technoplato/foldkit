Risks and failure modes

  • Instruction drift vs native gesture stacks. Rapid mode swaps project dismiss+present pairs; react-navigation can interleave animations. Adapters should coalesce pairs per frame or map onto native replace where available.
  • Deep-link canonicalization on generated routes. Generated screens must route params through the carrier, never navigate directly, or two sources of truth reappear.
  • forEach adoption is not free. Counters rows use field name counter; forEach uses child. Migration touches wire snapshots, so it needs a version bump on the tape schema.
  • Modal-on-home without a model field would push presentation state into clients, recreating exactly what ADR 0003 forbids. Decide before building the add-sheet.
