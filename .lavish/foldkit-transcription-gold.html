Recommended seam

Add a host, not another player

Keep the existing Words Program renderer-independent. Put Instant authentication, queries, mutation ordering, remote verification, and audio artifact resolution in adapters. Keep playback time and follow state local unless synchronized playback is an explicit feature.

Shared Domain

Recording identity, ordered transcript, finalization, speaker assignments, corrections, and artifact references.

Processor-local playback

Playing state, current time, active word, scroll/follow mode, scrub gesture, and native audio handle.

Independent remote truth

Admin-side entity IDs, final segment words, link ordering, offline-to-online convergence, and cleanup.

!
Do not synchronize every media time update through the accepted Message tape.

Toolshed's 50 ms polling is useful local UI input, but it is the wrong shared-data unit. Synchronize durable transcript facts. Keep the high-frequency playback cursor local, or emit only semantic boundary changes when remote control is intentionally enabled.

Suggested extraction order

A small, coherent path forward

This sequence preserves the tested Words core, makes the Instant boundary independently verifiable, and postpones reviewer breadth until the foundational media path is real.

Normalize the domain

Add Media, Run, Segment, and Word Schemas with explicit status unions, ownership, stable ordering, and positive time-range checks.

Host existing Words

Build an Instant-backed host/adapter around the same Program. Resolve audio through the existing artifact-stream boundary.

Port the usability gold

Add suspend/resume follow, stable segment anchors, resume position, keyboard transport, then speaker review as a separate route.

Prove the ugly cases

Run rapid volatile/final convergence, offline remote-truth acceptance, unordered/invalid word data, and seeded 36k-word performance gates.
