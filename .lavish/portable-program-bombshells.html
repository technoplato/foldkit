Bombshell 1

The server-client application divide is artificial.

Native stacks, browser history, terminals, servers, and every future host are adapters around one portable Program. Dependencies determine which side effects are authorized, not where the Program is allowed to run.

Bombshell 2

A link can identify a running application.

Portable state, event history, route, and capabilities can open in any medium. The same link can be public, encrypted, signed, scoped, revocable, or backed by a saved content-addressed tape.

Current Foldkit and the next codec

Content addressing exists. Compression is the missing layer.

Implemented now

Schema-encoded ReplayTape JSON, SHA-256-derived UUIDv8, ReplayTapeStore lookup, and integrity verification.

Missing now

A versioned canonical compact codec before hashing and saving. The current store hashes the encoded JSON string.

Generic first pass

Stable numeric event symbols, canonical payload bytes, dictionaries, sequence and time deltas, then deterministic byte compression.

Two things not to do

Do not sort the event stream because replay order matters. Do not replace payload bytes with only a hash because replay needs the original payload.

Capability vocabulary | draft

“Read” and “write” are not enough.

Observe

Read snapshots and subscribe to changes.

Create

Create selected entity types or append selected event cases.

Edit

Update selected entities, IDs, or fields.

Execute

Authorize Commands such as a transfer or external API operation.

Delegate

Grant a subset of capabilities to another identity.

Administer

Delete, rotate, revoke, and change policy.

Native Back performance evidence

The runtime can process a simple navigation Message synchronously.

Native Back prototype | measured

Strict prevents invalid presentation. Optimistic reveals it.

Strict Program-first

iOS header Back reached Program Home at 42 ms and native Home at 67 ms. Android hardware Back reached Program Home at 153 ms and native Home at 303 ms. No duplicate decision was observed.

Optimistic rejected Back

Native Home appeared first. Returning to the rejected Scene completed at 565 ms on iOS and 543 ms on Android, making the rollback visibly perceptible.

Prototype found real bugs

Container-level reconciliation fixed an unmounted-screen race. Attempt-scoped telemetry stopped late native events from contaminating a later trace.

Evidence still missing

Automated edge drags did not trigger an iOS interactive swipe. A genuine partially canceled swipe remains unverified and is not inferred from a native gestureCancel event.
