# Expo on iOS

A start string names a surface. The hospital must declare which surfaces it supports.

This surface is iOS, Expo, TypeScript. Expo may also be JavaScript.

```text
$ death start ios/expo/ts
started  device=ios  framework=expo  language=ts
```

```text
$ death start ios/expo/js
started  device=ios  framework=expo  language=js
```

React Native is a different framework slot on the same device:

```text
$ death start ios/react-native/ts
started  device=ios  framework=react-native  language=ts
```
