# Native Swift on Apple devices

A start string names a surface. Native Swift is a framework that those
devices allow. The hospital ADT lists only valid pairs. A generic
device plus framework struct is not enough.

```text
$ death start ios/native/swift
started  device=ios  framework=native  language=swift
```

```text
$ death start ipados/native/swift
started  device=ipados  framework=native  language=swift
```

```text
$ death start macos/native/swift
started  device=macos  framework=native  language=swift
```

```text
$ death start tvos/native/swift
started  device=tvos  framework=native  language=swift
```

These four devices share the native Swift framework slot. Expo stays
on the devices that allow Expo. CLI is a different device. It may use
a custom framework (`cli/custom/ts`).
