# Rust start prints

Start names a surface, not a lock-in. Lock-in stays `counter:level:show`.
Nest device, then only frameworks that device allows, then language.
Rust is a CLI language in these public examples. Start always opens a
new device.

```text
$ death start cli/custom/rs
started  device=cli  framework=custom  language=rs
```

A named CLI framework uses the same nest. Clap is a real CLI parser:

```text
$ death start cli/clap/rs
started  device=cli  framework=clap  language=rs
```

`cli/noncaptive/rs` is illegal. Non-captive describes a CLI, not a
framework. `macos/expo/rs` is unrepresentable.
