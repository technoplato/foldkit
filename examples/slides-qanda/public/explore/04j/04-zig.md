# Zig start prints

Start names a surface, not a lock-in. Lock-in stays `counter:level:show`.
Nest device, then only frameworks that device allows, then language.
Zig is a CLI language in these public examples. Start always opens a
new device.

```text
$ death start cli/custom/zig
started  device=cli  framework=custom  language=zig
```

A named CLI framework uses the same nest:

```text
$ death start cli/<framework>/zig
started  device=cli  framework=<framework>  language=zig
```

`cli/noncaptive/zig` is illegal. Non-captive describes a CLI, not a
framework. `macos/expo/zig` is unrepresentable.
