# Python start prints

Start names a surface, not a lock-in. Lock-in stays `counter:level:show`.
Nest device, then only frameworks that device allows, then language.
Python is a CLI language in these public examples. Start always opens a
new device.

```text
$ death start cli/custom/py
started  device=cli  framework=custom  language=py
```

A named CLI framework uses the same nest. Click is a real CLI library:

```text
$ death start cli/click/py
started  device=cli  framework=click  language=py
```

`cli/noncaptive/py` is illegal. Non-captive describes a CLI, not a
framework. `macos/expo/py` is unrepresentable.
