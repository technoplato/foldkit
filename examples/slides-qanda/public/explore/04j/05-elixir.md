# Elixir start prints

Start names a surface, not a lock-in. Lock-in stays `counter:level:show`.
Nest device, then only frameworks that device allows, then language.
Elixir is a CLI language in these public examples. Start always opens a
new device.

```text
$ death start cli/phoenix/ex
started  device=cli  framework=phoenix  language=ex
```

LiveView Phoenix will not work for offline tests. Offline is a scored
rung. A LiveView page that needs the Phoenix server cannot take that
test.

```text
$ death start cli/custom/ex
started  device=cli  framework=custom  language=ex
```

`cli/noncaptive/ex` is illegal. Non-captive describes a CLI, not a
framework. `macos/expo/ex` is unrepresentable.
